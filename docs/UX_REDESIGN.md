# Новый интерфейс NorskLive Pro: структура и экраны

Кто читает: владелец, Antigravity (исполнитель), Claude Code (ревью).
Основание: `docs/APP_AUDIT_2026-09-30.md`, `docs/DESIGN_SYSTEM.md`. Решение владельца от 30 сентября 2026: согласована структура из семи экранов и два вида практики.
Правило: **один экран, одно главное действие**. Всё, что не нужно прямо сейчас, спрятано или перенесено на другой экран.

## 1. Карта экранов
```
Сегодня  ──►  Практика  ──►  Разбор (после каждой реплики)  ──►  Итог
   │              ▲
   ├──► Выбор темы (нижняя шторка)
   ├──► Слова (M1f)
   └──► Профиль и настройки
```
| Экран | Адрес | Единственное главное действие |
|---|---|---|
| Сегодня | `/` | «Начать практику» |
| Практика | `/practice` | микрофон «Говорить» / «Готово» |
| Разбор | внутри `/practice` | «Дальше» |
| Итог | `/practice/result` | «На главную» |
| Выбор темы | шторка на «Сегодня» и «Практика» | выбрать тему |
| Слова | `/words` | «Начать повторение» |
| Профиль | `/profile` | (нет главного, только настройки) |

`/studio` остаётся, но перенаправляет на `/practice`, старые ссылки не ломаются. Панель «Материалы» удаляется целиком.

## 2. Два вида практики
- **Учёба.** После каждой реплики разбор и подсказки. Можно повторить реплику.
- **Экзамен.** Без подсказок и без разбора до конца части, время как на экзамене HK-dir, Нора «ждёт снаружи». Разбор и оценка приходят на экране «Итог».
Переключатель на «Сегодня» (две карточки-варианта) и в шторке «Выбор темы». По умолчанию «Учёба».

## 3. Экран «Сегодня» (`/`)
```
┌───────────────────────────────┐
│ ( Нора )  Здравствуйте, Анна  │   заголовок: одно предложение
│                               │
│  Сегодня: 10 минут практики   │   .t-title
│  До экзамена 42 дня           │   если дата задана
│                               │
│  [   Начать практику   ]      │   единственная filled-кнопка
│  Тема: Работа · Изменить      │   текстовая кнопка -> шторка
│                               │
│  Слова на сегодня: 8   Повторить  (outline)
│  Мой путь: A2 → B1  ▓▓▓░░     │   одна полоса прогресса
└───────────────────────────────┘
```
Правила:
- Не больше трёх блоков: практика, слова, путь. Никаких заглушек «Оплата скоро»: карточка тарифа показывается только когда оплата работает или когда исчерпан лимит.
- Дата экзамена спрашивается один раз в приветствии; здесь только показывается и меняется в «Профиле». Формат по языку интерфейса (`ДД.ММ.ГГГГ`).
- Выбор темы: «Работа», «Врач», «Жильё», «Семья», «Магазин», «Транспорт», «Свободное время» (7 тем экзамена) и «Своя тема».

## 4. Приветствие (первый запуск)
Цель: **первая победа за 60 секунд**, а не экзаменационный монолог.
1. Язык объяснений (ru / uk / en). Спрашивается первым, интерфейс сразу переключается.
2. Уровень цели (A2 / B1) и дата экзамена (можно «Пока не знаю»).
3. Сразу мини-практика «Знакомство» (3 вопроса уровня A2: «Hva heter du? Hvor kommer du fra? Hva jobber du med?») с разбором после каждой реплики. Нора говорит вслух, ученик отвечает голосом или текстом.
4. Итог мини-практики: «Вы сказали 3 фразы» и что получилось хорошо. Только потом «Сегодня».
Пропустить можно на каждом шаге; пропуск ведёт на «Сегодня» с мягкой карточкой «Пройти знакомство» (по навыку onboarding-wizard-design: пропуск не оставляет пустой продукт).

## 5. Экран «Практика» (`/practice`)
```
┌───────────────────────────────┐
│ ‹  Работа · Учёба     02:14   │   назад, тема+вид, таймер
│───────────────────────────────│
│  Экзаменатор                  │
│  «Hva jobber du med?»         │   .t-speech, одна реплика
│  ▸ Перевод   ▸ Слушать        │   перевод свёрнут, 44 px
│                               │
│  Ваш ответ                    │   после «Готово»: текст
│  «Jeg jobber som ...»         │   можно править
│                               │
│  ( Нора: слушает )            │
│                               │
│        (  Говорить  )         │   MicButton 72 px
│        Написать ответ         │   текстовая кнопка, раскрывает поле
└───────────────────────────────┘
```
Правила:
- Одна реплика экзаменатора на экране. История доступна кнопкой «История» (шторка), не по умолчанию.
- Нет баннера «ЭТАП», нет второго дублирования задания. Название части («Часть 1. Расскажите о себе», «Часть 2. Опишите картинку», «Часть 3. Разговор») показывается одной строкой в шапке.
- Часть 2 показывает картинку над репликой.
- Запись: «Говорить» → «Готово» (запись идёт до нажатия), текст показывается до отправки, «Отправить» одной кнопкой; настройка «Отправлять сразу».
- В режиме «Экзамен» скрыты: перевод, подсказки, «Слушать ещё раз» не более одного раза (как на экзамене).
- Все кнопки ≥ 44 px, статус записи озвучивается (`aria-live`).

## 6. Экран «Разбор» (учёба)
Появляется после ответа как нижняя карточка на месте микрофона. Порядок сверху вниз:
1. Если ошибок нет: «Хорошо!» и одна конкретная похвала («Вы правильно поставили глагол на второе место»). Ничего не зачёркивается.
2. Если есть ошибки: **одна главная ошибка**: фраза ученика с выделенным неверным местом (`<del>`), исправление (`<ins>`), название правила и объяснение на языке ученика (свёрнуто, кнопка «Почему?»).
3. «Ещё N замечания» раскрывает остальные.
4. «Как сказать лучше» (необязательно, свёрнуто) с версией на уровень выше.
5. Кнопки: **«Дальше»** (filled) и «Повторить фразу» (outline).
Данные приходят из новой схемы ответа ИИ (см. задачу по схеме): список реальных ошибок, флаг «ошибок нет», уровень цели. Ни при каких условиях не показывается заготовленный текст как ответ ИИ.

## 7. Экран «Итог»
- Четыре критерия HK-dir (произношение, словарь, грамматика, взаимодействие) полосой `ScoreBar`, без процентов, с пометкой «Оценка ориентировочная, это тренажёр, а не экзамен».
- «Что улучшить»: 1–3 пункта.
- «Слова для повторения»: слова, на которых человек споткнулся; кнопка «Добавить в мои слова».
- Одна filled-кнопка «На главную», рядом outline «Пройти ещё раз».

## 8. Шторка «Выбор темы»
Список 7 тем + «Своя тема» (поле для вставки текста или вакансии до 4 000 знаков, с пояснением «Текст останется в браузере и уйдёт только для ответа»). Внизу переключатель «Учёба / Экзамен». Никаких агентов, «Blur», «Persona», «Bingo».

## 9. «Профиль и настройки»
Язык объяснений, уровень цели, дата экзамена, размер текста, темп речи, субтитры экзаменатора, повышенный контраст, «Отправлять сразу после «Готово»», голос экзаменатора (когда появится выбор), аккаунт (вход по почте, выход, удаление). Нет ссылок на лабораторные страницы.

## 10. Язык и тексты
- Один язык интерфейса: язык ученика (ru, uk, en). Норвежский только в реплике экзаменатора, примерах и словах.
- Запрещены англицизмы-жаргон: «Agent», «Blur», «Persona», «Bingo», «Cultural Fit», «Micro-correction», «R&D», «Matrix». Названия: «Практика», «Разбор», «Итог», «Слова».
- Кнопки называют действие: «Начать практику», «Говорить», «Готово», «Дальше», «Повторить».
- Ошибки говорят, что делать дальше. Без смайлов, без кодов ошибок.
- `<html lang>` по языку интерфейса, `lang="nb"` на норвежском.

## 11. Что удаляется
Панель «Материалы» целиком, выбор «Агента» и «Persona», «Blur (Аудирование)», «Bingo 10 слов», «HK-dir Матрица», «Трансформация фраз», кнопка «Скачать отчёт» посреди практики, карточка «Подписка: оплата скоро», баннер «ЭТАП» и кнопка «К Этапу 2» (переход между частями делает приложение).
Что из удалённого нужно сохранить как функцию: «Мой словарь» → экран «Слова»; отчёт → экран «Итог» (кнопка «Скачать» там); «Своя тема» → шторка «Выбор темы».

## 13. Как мы поймём, что стало лучше
- Первый экран практики: не больше 50 слов и 4 интерактивных элементов.
- Приветствие: от открытия до первой сказанной фразы ≤ 60 секунд.
- Нет ни одного визуального элемента, который нельзя объяснить одной фразой.
- Владелец проходит `docs/TEST_CHECKLIST.md` на телефоне и ноутбуке и ставит оценку не ниже 6 из 8.
