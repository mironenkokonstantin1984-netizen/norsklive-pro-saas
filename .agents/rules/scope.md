# Scope rules

- The issue text and its acceptance criteria define the work. Nothing more.
- Do not start the next milestone, even if it looks easy.
- Do not reformat, rename or move files the task does not mention.
- Do not add dependencies the task does not need; justify every new dependency in the PR report.
- If a requirement is ambiguous or impossible, do the unambiguous part, then list the open
  question under "Blocked / questions" in the PR report instead of guessing.
