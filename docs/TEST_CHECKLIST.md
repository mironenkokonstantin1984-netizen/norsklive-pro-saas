# Ручной чек-лист тестирования (NorskLive Pro)

## 1. Старт и навигация
- [ ] Открыть `/` — загружается экран практики с приветственной репликой экзаменатора и кнопкой микрофона (`#micToggleBtn`).
- [ ] Открыть `/studio` — отображается тот же интерфейс тренажёра без ошибок в консоли.
- [ ] Открыть `/norsk` — происходит автоматический редирект (`308`) на `/`.
- [ ] Открыть несуществующий адрес `/unknown-page` — отображается корректная страница `404`.

## 2. Текстовый ответ и ответ экзаменатора
- [ ] Ввести фразу на норвежском в поле `#userSpeechInput` и нажать «Отправить» (`#sendSpeechBtn`) — сообщение пользователя появляется в диалоге, поле ввода очищается.
- [ ] Дождаться ответа `/api/coach` — появляется новая реплика экзаменатора на норвежском (`reply_norsk`).
- [ ] Проверить карточку разбора (`CorrectionCard`) после ответа — отображаются оригинал с зачёркиванием (`<del>`), естественный вариант (`<ins>`), правило на L1 и вариант уровня B2.
- [ ] Нажать на подсказку (Hint pill) под диалогом — текст подсказки подставляется в `#userSpeechInput` и фокусирует поле.
- [ ] Отправить 5 реплик подряд — после 5-го хода появляется ненавязчивая карточка самочувствия «Как ощущения?».

## 3. Микрофон (Chrome, Edge, Safari)
- [ ] В Chrome или Edge нажать `#micToggleBtn` и разрешить доступ к микрофону — статус меняется на «Слушаю…», распознанная речь попадает в `#userSpeechInput`.
- [ ] Повторно нажать `#micToggleBtn` во время записи — запись останавливается, статус возвращается в исходное состояние.
- [ ] Запретить доступ к микрофону в настройках браузера и нажать `#micToggleBtn` — появляется понятное сообщение об отказе в доступе, текстовый ввод `#userSpeechInput` остаётся доступным.
- [ ] Открыть в браузере без поддержки `SpeechRecognition` (или при недоступном API в Safari/Firefox) — кнопка микрофона не ломает страницу, отображается подсказка о вводе текстом.

## 4. «Выбор темы» (TopicSheet)
- [ ] Нажать на заголовок темы в шапке практики (`.practice-header-title-btn`) — открывается шторка выбора тем (`TopicSheet`), атрибут `aria-expanded` меняется с `"false"` на `"true"`.
- [ ] Нажать Escape или кликнуть по оверлею — шторка закрывается, фокус возвращается на триггер.
- [ ] Выбрать другую тему из 7 тем экзамена — сценарий обновляется под выбранную тему.
- [ ] Ввести свой текст в «Своя тема» (до 4 000 символов) и нажать «Выбрать свою тему» — создаётся пользовательский сценарий.
- [ ] Переключить режим «Учёба | Экзамен» — режим переключается, в экзамене скрываются подсказки.

## 5. Профиль и настройки (`/profile`)
- [ ] Открыть `/profile` (через иконку профиля в шапке главной или напрямую) — отображаются 5 групп настроек (Язык и уровень, Практика, Голос, Вид, Аккаунт).
- [ ] Выбрать тему «Светлая» / «Тёмная» / «Системная» — `document.documentElement` получает `data-theme`, фон и карточки обновляются мгновенно.
- [ ] Включить «Усиленный контраст» — `data-contrast="true"`, усиливается контраст границ и текста.
- [ ] Переключить размер текста (`Обычный` / `Крупный` / `Очень крупный`) — `data-text-size` принимает `sm` / `md` / `lg`, шрифты масштабируются пропорционально.
- [ ] Перезагрузить страницу — выбранные настройки сохраняются из `localStorage` (`norsklive_prefs`, `norsklive_path`).

## 6. Телефон (390 × 844 px)
- [ ] Открыть `/` и `/profile` во вьюпорте `390×844` — шапка помещается в одну компактную строку, горизонтальный скролл отсутствует.
- [ ] Проверить шторку `TopicSheet` на `390×844` — высота строк тем не менее 56 px, область нажатия не менее `44×44 px`.
- [ ] Проверить круглую кнопку микрофона (`#micToggleBtn`) и строку ввода на `390×844` — размер области нажатия не менее `44×44 px` (микрофон `72×72 px`), элементы не перекрывают друг друга.

## 7. Вход по e-mail (при `AUTH_ENABLED=true`)
- [ ] При `AUTH_ENABLED=true` без сессии отправить запрос в `/api/coach` (или открыть защищённое действие) — возвращается `401`, интерфейс предлагает войти на `/login`.
- [ ] На странице `/login` ввести e-mail и нажать «Получить ссылку для входа» — отображается сообщение об отправке письма.
- [ ] В локальном Mailpit (`http://localhost:54324`) открыть письмо и перейти по magic-link (`/auth/callback?code=...`) — создаётся сессия и происходит переход на `/`.

## 8. Ошибки: нет сети, нет API-ключа → офлайн-фоллбэк
- [ ] Запустить сервер с пустым `GEMINI_API_KEY=""` и отправить ответ в `#userSpeechInput` — `/api/coach` возвращает `200` от детерминированного офлайн-фоллбэка (реплика экзаменатора и коррекция отображаются без ошибок).
- [ ] Отключить сеть в DevTools (`Offline`) и нажать «Отправить» — интерфейс показывает понятное уведомление об ошибке соединения и не зависает в бесконечной загрузке.
- [ ] Отправить пустую строку или пробелы — отправка блокируется валидацией без падения приложения.
